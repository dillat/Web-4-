# Извлечение именованных сущностей из рецептов

## Обзор проекта

В качестве темы для работы в течение семестра была избрана Б6. Извлечение состава и действий из рецептов. В случае успешного окончания работы сервис находит ингредиенты, количества, действия, время приготовления блюда.

Проект объединяет методы обработки естественного языка (NLP) и разработку веб-приложений.

Задачи проекта:

*   Определить типы сущностей, подлежащих извлечению из текстов рецептов.
*   Разработать NLP-компонент для идентификации и классификации сущностей.
*   Установить единый формат данных для результатов извлечения.
*   Разработать веб-интерфейс для ввода рецептов и просмотра результатов.
*   Интегрировать и протестировать NLP-компонент и веб-часть системы.
*   Документировать реализацию, интерфейсы и процесс оценки качества работы.

## Ожидаемый рабочий процесс

1.  Ввод текста рецепта.
2.  Обработка текста с помощью NLP-компонента.
3.  Извлечение и классификация согласованных типов сущностей.
4.  Возврат результатов в согласованном формате данных.
5.  Отображение извлеченной информации в веб-интерфейсе.
6.  Оценка и документирование эффективности работы системы.

## Статус проекта

Репозиторий и спецификации проекта находятся в стадии разработки. Команда согласует итоговую схему сущностей, техническую архитектуру, критерии оценки и детали реализации.
