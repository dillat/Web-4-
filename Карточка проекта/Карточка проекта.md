# Задача

Входные данные: Текст рецепта.

Выходные данные: Структурированное представление информации, извлеченной из рецепта (ингредиенты, количества, единицы измерения).

Для кого и зачем:

Потенциальные пользователи — люди, желающие преобразовать неструктурированные тексты рецептов в структурированные списки ингредиентов, а также приложения, которым необходима информация о рецептах в машиночитаемом формате.

# Проверка выбора темы

Протестированная предобученная модель: Будет определена позже.

Объем выборки для оценки: 20 примеров.

Результаты предобученной модели: Подлежат измерению.

Почему существующей модели может быть недостаточно: Будет установлено экспериментально. Возможные проблемы: ошибки распознавания названий ингредиентов, сопоставления количеств с соответствующими ингредиентами, обработки единиц измерения и специфической лексики рецептов.

Если готовая модель показывает достаточно хорошие результаты, задачу следует сузить: выбрать более узкую предметную область (тип рецептов) или выделить более специфические категории сущностей.
